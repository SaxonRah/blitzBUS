$env:BB_SD_BOOT = "1"

[9] UNDERSTAND OPTIONS AND WHERE TO CHANGE THEM

Where to edit YOUR choices:
  bb_dos_build_options.ps1 in this downloaded reference folder.

Where the installer reads the BB_* variables and supplies defaults:
  C:\blitzBUS\scripts\install_live.py
  Don't hand-edit this generated/lineage-sensitive implementation.

Parameter           Current choice     Purpose / notes
------------------  -----------------  ------------------------------------------
BB_SD_BOOT          1                  Required SD-boot overlay selection
BB_CPU              286                Existing DOS 6.22 build is 286 real mode
BB_PAGED            1                  Use paged guest memory
BB_HOT_THRESHOLD    32                 JIT promotion threshold
BB_EVICT_CHUNK      4096               JIT code-cache eviction chunk
BB_EVICT_ROOM       2048               Cache free-room threshold
BB_BBUF             1                  SRAM backbuffer enabled
BB_CODE_KB          232                JIT code cache allocation
BB_LCD_PERI_HZ      150000000          LCD peripheral clock
BB_LCD_SPI_HZ       75000000           LCD SPI rate
BB_LCD_LACE         1                  Alternating-row LCD updates (0 = full)

The EVICT variables, BBUF, PAGED and HOT_THRESHOLD already have defaults in
install_live.py; keeping their values explicit merely records the known-good
configuration. BB_CPU's GENERATOR DEFAULT IS 8086, not 286: do not forget to
set BB_CPU=286 before a future DOS 6.22 rebuild.

This live-build installer only accepts BB_CPU=8086, 186 or 286. Setting
BB_CPU=386 or 486 will be rejected. Getting the Descent GAME running after
installation still requires separate 386/protected-mode compatibility work.
